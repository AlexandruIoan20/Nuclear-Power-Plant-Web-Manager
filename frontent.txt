Prezentarea arhitecturii frontend

.
├── modules
│   ├── config | Scripturi de configurare / setup pentru proeict
│   │   └── api.config.js | Configurarea pentru backend: Contine baza url ului backendului
│   ├── core | Scripturi de baza / wrappere
│   │   └── api.js | Wrapper pentru functia fetch 
│   ├── dto | Data Transfer Objects (fetch se apeleaza doar cu astfel de DTO uri)
│   │   ├── CreatePlantRequestDTO.js
│   │   └── UpdatePlantRequestDTO.js
│   ├── pages | Logica JS a paginilor HTML
│   │   └── plant-create.js
│   ├── services | Aici se fac requesturi la backend. Service-ul este instantiat la nevoie in directorul pages la fisierul dorit
│   │   └── powerPlantService.js
│   └── ui | Helpers pentru manipularea UI ului 
│       └── showMessage.js
├── pages | Paginile HTML dupa ierarhia de fisiere dorita
│   └── power-plants
│       └── create.html
└── style.css
